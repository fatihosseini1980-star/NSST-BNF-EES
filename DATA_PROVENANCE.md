# Data provenance

The response is the pollutant-specific PM2.5 AQI sub-index, expressed in index points, not PM2.5 mass concentration. The input file `data/source_daily_aqi.csv` contains 90,023 nonmissing daily values with English station IDs and Gregorian year/month fields. The released screened analysis excludes both ambiguous entries `Sharif` and `Shahrdari-2` because their complete daily series coincide despite different assigned geographic coordinates. A single value of 500 from `Farmandari-rey` (September 2015) is omitted only in the designated conservative scenario. It is not independently established to be erroneous; the fully refitted retain-500 sensitivity result is included. No 2024 values were removed according to their predictive errors.

The screened data contain 83,478 daily observations and 3,348 station-months across all available years. The 2014--2024 panel contains 3,267 station-months at 36 stations. The fixed temporal split is 2,633 train (through 2022), 319 validation (2023), and 315 retrospective test (2024). The 2024 test period was historically inspected and should not be presented as a newly untouched holdout. Input/response scalers are estimated on training only, and validation is used for predictive calibration.

`prepare_tehran.py` derives the two declared monthly datasets from the source daily CSV using station metadata. Geography is provided in WGS84. The 12-panel regional surface uses thin-plate-spline cartographic interpolation of 22 model-derived representative-point predictions in each month, not areal averaging or direct dense-grid neural-field prediction.
